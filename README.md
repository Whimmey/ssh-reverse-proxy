# ssh-reverse-proxy

本地开着 VPN，代理一切正常；SSH 连上服务器后，Codex CLI 却连不上服务。原因很简单：远程终端读不到你本地的代理。

ssh-reverse-proxy 为多人共用的服务器提供一条命令，帮助指导用户把本地电脑的 HTTP 代理接到服务器上，供远程终端里的程序使用。端口按 UID 自动分配，用户之间不会冲突。

运行 `ssh-reverse-proxy` 后，脚本会询问本地代理软件的监听端口，以及本地 `~/.ssh/config` 中该服务器的 Host 别名，随后把这些配置写入当前用户的 `~/.bashrc`，并输出一条需要在**本地电脑**执行的 SSH 命令。

VPN 的启动与 SSH 隧道的建立均不由脚本代劳。

## 原理

核心机制是 SSH 的远程端口转发（`ssh -R`），即反向隧道：服务器上的一个端口，经 SSH 连接转发到本地主机的代理端口。新建的远程终端会从 `~/.bashrc` 读取 `http_proxy`、`https_proxy` 等变量并指向该端口，凡是读取这些变量的程序即自动使用本地代理。

服务器端口由 UID 推导：`UID + 10000`。这样多人共用一台服务器时，各人的端口天然错开，无需中央登记或手工分配。

```text
服务器上的程序 → 服务器 127.0.0.1:11234 → SSH 远程端口转发
                                          → 本地 127.0.0.1:7892 → 本地 VPN/代理
```

图中以 UID `1234`（服务器端口 `11234`）、本地代理端口 `7892` 为例。本地代理端口和 SSH 别名由使用者填写，服务器端口由脚本按 UID 算出。另外，普通 SSH 登录和 VS Code 远程终端都不会替你建立转发。

## 使用

管理员按 [INSTALL.md](INSTALL.md) 安装后，用户在服务器终端运行：

```bash
ssh-reverse-proxy
```

按提示填写**本地电脑**代理软件的端口，以及本地 `~/.ssh/config` 中连接该服务器的 Host 别名。脚本会回显分配到的服务器端口、当前配置、需要在本地执行的 SSH 命令，以及一条验证命令。

以服务器端口 `11234`、本地代理端口 `7892`、Host 别名 `my-server` 为例，在**本地电脑**执行脚本给出的命令：

```bash
ssh -N -R 11234:127.0.0.1:7892 my-server
```

该命令把服务器上的 `127.0.0.1:11234` 转发到本地主机的 `127.0.0.1:7892`。请保持这个终端窗口打开——窗口关闭后隧道即中断。

隧道建立后，新开一个远程终端验证：

```bash
curl -x http://127.0.0.1:11234 -I https://api.openai.com/v1/models
```

收到目标服务返回的 HTTP 响应即说明请求已到达。这只验证连通性，不代表 Codex CLI 的登录状态正常。

后续只需重新建立隧道时，在本地重跑那条 SSH 命令即可。需要重新查看命令，或修改本地端口与 SSH 别名时，再次运行 `ssh-reverse-proxy`。

此外，可以通过 `ssh-reverse-proxy off` 关闭新终端中的代理环境变量，`ssh-reverse-proxy on` 重新启用；切换后请新开远程终端。

## 自定义命令别名（可选）

`ssh-reverse-proxy` 输入起来略长，可以在服务器端为它建个别名。例如叫 `ssrep`：

```bash
echo "alias ssrep='ssh-reverse-proxy'" >> ~/.bashrc
source ~/.bashrc
```

此后 `ssrep`、`ssrep on`、`ssrep off` 都与 `ssh-reverse-proxy` 等效。别名由使用者自行维护，脚本不会写入或修改它。注意别名只在交互式 shell 中展开；脚本或非交互式调用请直接写 `ssh-reverse-proxy`。

## 适用范围

- 仅支持 Bash，配置写入运行命令者自己的 `~/.bashrc`，登录时不会自动初始化。
- 服务器端口固定为 `UID + 10000`，因此 UID 不得大于 `55535`。脚本不检测该端口是否已被其他程序占用。
- 已有独立代理配置，或手动设置过 `SRP_SERVER_PORT` 的用户，需先自行处理冲突——脚本会拒绝覆盖。
- `~/.bashrc` 中会保存本地代理端口与 SSH Host 别名。个人的 `~/.bashrc`、SSH 配置与运行时状态请勿提交至公开仓库。
